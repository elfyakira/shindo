## 所見

### 主要な差分（修正推奨度：高）

1. **Companyページ - 沿革セクションのレイアウト**
   - カンプ: 年度の右側に横バー（プログレスバー風）があるビジュアルリッチなデザイン
   - 実装: シンプルなテーブル（年度+テキスト）
   - **修正推奨度: 高**
   - 対象ファイル: `src/app/company/page.tsx` (HistorySection)

2. **Businessページ - Heroセクションの画像配置**
   - カンプ: 2枚の画像を左右に配置（左：重機、右：作業員）
   - 実装: 1枚のフル幅画像
   - **修正推奨度: 高**
   - 対象ファイル: `src/app/business/page.tsx` (HeroSection)

3. **Businessページ - 緑背景セクションの連続性**
   - カンプ: 太陽光発電・現場見学・清掃活動が連続した緑背景で区切りなし
   - 実装: 各セクションにpaddingがあり、間隔が開いている
   - **修正推奨度: 中**
   - 対象ファイル: `src/app/business/page.tsx` (SolarPowerSection, SiteVisitSection, CleaningSection)

### 軽微な差分（修正推奨度：低）

4. **Recruitページ - Hero高さ**
   - カンプでは50%程度に見えるが、実装は70vh
   - **修正推奨度: 低**（デザインの意図次第）
   - 対象ファイル: `src/app/recruit/page.tsx` (HeroSection)

### 一致している項目

- テキスト・文言は概ねカンプ通り
- 色・カラーは主要部分で一致
- 大部分のレイアウト・配置は一致
- フォント・サイズは概ね適切
- 余白・間隔は大部分で適切
